# Changelog

## 1.1.0 — 2026-10-14

- Added a live Focus on hover toggle near the top of the menu.
- Remember successful selections and restore them after app/daemon restarts or reconnection.
- Confirm setting changes before saving; show unavailable and failure states without blocking menu refreshes.
- Added native menu-action and restart/failure tests plus an explicit live smoke test.

## 1.0.0 — 2026-09-17

- Native AeroSpace-inspired numbered Space indicators in the existing macOS menu bar.
- App/window overview by desktop, with a read-only macOS fallback.
- Optional spiral tiling configuration and five app/float shortcuts.
- Centered floating windows covering approximately 50% of usable screen area.
- Portable local build, bundled offline reference, and explicit backup-aware installation.
- Automated native/helper/installer checks and macOS CI.
